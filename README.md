# How to use
- It is **Not Cross platform**, it only works on **Windows**.
- You can have a chat with it like "Hello", "How are you?" et cetera.
- You can give it commands like open notepad, delete this folder.

💡**Remember**
> It is a very powerful AI.   
> Always check what it is about to do before accepting.   
> **DO NOT** give it commands like delete my temporary files, as it can misunderstand the prompt and delete important files.
